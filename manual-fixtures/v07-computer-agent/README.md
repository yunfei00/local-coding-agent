# v0.7 轻量本地网页视觉回退

复用仓库 Electron 运行时，验收驱动在隔离目录链接依赖，不访问外网网页。Canvas 中按钮的位置每次随机，UIA 无该按钮的 Invoke 控件。模型必须读取本次授权截图、根据实际图片定位，再经审批点击并检查真实结果；不得读取源码推算位置或用脚本/IPC 代替操作。

`.runtime/result.json` 只由实际 Canvas 点击事件写入。测试结束停止本次进程；不处理用户浏览器或其他窗口。属于测试工程，不是产品内置另一个浏览器自动化系统。

监督诊断、截图分析结果和报告必须写在被测工作区之外。即使只是只读 UIA 检查，其输出文件也会被工作区快照识别为新文件，导致纯 GUI 场景误入代码变更验证；这种受污染的测试应保留并判无效，使用全新夹具复验，不得删除文件后冒充原任务通过。
