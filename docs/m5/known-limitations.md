# 已知限制

- 本轮不调用真实付费模型。已证明 Mock 决策驱动的真实工具/工程/GUI闭环，尚不能宣称任意自然语言任务已由真实在线模型自主完成，更不能宣称完整替代 Codex。
- Windows GUI 要求解锁且同一交互会话。遮挡、窗口越界、UAC、敏感控件、UIA 缺失/树截断会明确拒绝；不会扩权或退化为盲坐标输入。
- Chromium 输入路径只用于精确可编辑 UIA Edit，原生 Edit 使用 ValuePattern；自绘编辑器/无 ValuePattern/焦点不可验证时仍拒绝。输入法、不同语言布局、多显示器/不同 DPI 全组合尚未穷举。
- 本轮实际系统捕获覆盖 WinForms、记事本、计算器和 Electron；不是所有 Windows 应用兼容性保证。模型语义视觉准确度尚未在线验证。
- 验收保护冻结既有测试、配置、测试/构建及 GUI 启动脚本。合法修改这些文件需要人检查新基线；不会静默放开以通过测试。应用代码仍须最终人工 Diff 审查。
- Token 预算请求前保守预留，实际 Usage 由服务端结算；未知/中断请求保留预留。价格未知不虚构费用。
- 旧裸模型名缺少历史连接信息时不能恢复歧义绑定；保留旧记录并提示重选。
- 固定 fixture 的原始源码故意保留两个缺陷；成功修改在临时 Task Worktree，测试结束自动清理。手工公司验证请使用实验副本。
- 无 Tag、Release、Setup、Portable；完成 M5 后停止，不自动进入 M6。
