## 本轮执行原则

- 保留用户数据，使用临时工程与独立数据目录；迁移只处理备份副本。
- 在 `feature/v0.3` 分阶段提交；完成本地检查后检查对应提交的 Windows / Ubuntu CI。
- 真实工具记录作为计划证据；不存储隐藏推理，诊断只保留有限的白名单元数据。
- Setup、Portable、迁移、CI 和人工视觉确认全部满足后才合并 main。
- 不创建正式 tag，不发布 GitHub Release。

## 环境差异

实测 Node 为 v24.14.0、npm 为 11.9.0（附件列出 v24.19.0 / 11.17.0）。先验证现有版本兼容性，不擅自升级系统软件。
