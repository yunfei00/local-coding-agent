# v0.3 Phase 27 — 执行与上下文观测验收

日期：2026-10-22。分支：`feature/v0.3`。

## 已接入的运行路径

- `TurnMetrics` 接入实际 Agent Loop，统计 Provider、Model、模型步骤、工具调用/耗时/失败与 Provider 重试。
- `turn.completed.execution_summary` 和每个终止路径的 `turn.metrics` 正式协议事件携带指标。
- Token 估算与来源来自 ContextBudgetManager，history / tool_output 按实际保留的消息计算，显式文件和仓库索引使用各自预算贡献。
- 桌面展示可展开的紧凑摘要，并支持复制白名单脱敏轨迹。
- Diagnostics 展示 MCP、Worktree、Repository Map 和当前 Agent 运行状态。
- 最近一轮统计仅保留固定大小元数据，不在 SQLite 累积原始轨迹或隐藏推理。
- API Key、Bearer、Authorization、MCP 凭据、敏感环境变量、URL 凭据和查询秘密过滤；普通 Token 计数保留。

## 自动验收

```powershell
uv run python -m unittest discover -s tests -p test_turn_metrics.py -v
uv run python -m unittest discover -s tests -p test_v03_runtime.py -v
npm.cmd --prefix desktop test
npm.cmd --prefix desktop run build
node scripts/validation/desktop-smoke.cjs
```

运行时测试核对重试、真实工具执行、权限拒绝与来源预算；桌面冒烟运行实际 Electron、Python Agent、本地 OpenAI 兼容服务与 MCP stdio / HTTP 服务。完整报告仅保存在本地 `validation-reports`，不自动上传。

## 人工复核

1. 执行包含工具调用的任务，展开底部摘要，核对模型轮次、工具次数与耗时。
2. 测试失败或权限拒绝时，失败计数必须递增；Stop 后仍可看到该轮统计。
3. Pin 文件并查看来源贡献，打开 Diagnostics 核对运行状态、MCP、Worktree 与索引修订号。
4. 点击 Copy sanitized trace 和 Copy report，确认没有原始提示词、工具参数、API Key、凭据或隐藏推理。

实现情况和实际测试数量以 [最终验收记录](v0.3-final-validation.md) 为准，不能把本说明当作通过证据。
