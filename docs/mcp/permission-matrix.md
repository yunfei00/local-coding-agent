# 完整权限矩阵

| 操作 | READ_ONLY | APPROVAL | WORKSPACE | FULL_ACCESS | RESTRICTED |
|---|---|---|---|---|---|
| 文件读取/搜索/列表 | 允许 | 允许 | 允许 | 允许 | 允许（白名单） |
| 文件创建/修改/删除 | 拒绝 | 审批 | 审批/策略 | 允许（高风险仍受限） | 拒绝 |
| 工作区外访问 | 拒绝 | 审批 | 审批 | 审批/策略 | 拒绝 |
| Shell 命令执行 | 拒绝 | 审批 | 审批/风险策略 | 允许（高风险/凭据/系统保护受限） | 拒绝 |
| Git 只读 | 允许 | 允许 | 允许 | 允许 | 允许（白名单） |
| Git commit/push/worktree | 拒绝/需明确意图 | 审批+明确意图 | 审批+明确意图 | 仍需明确意图/高风险策略 | 拒绝 |
| 网络访问/MCP 调用 | 只读可信MCP可允许 | 按工具权限 | 按工具权限 | 按工具权限/高风险策略 | 默认拒绝，显式白名单才允许 |
| 外部程序执行 | 拒绝 | 审批 | 审批 | 审批/策略 | 拒绝 |
| 子Agent/后台任务 | 按产品入口控制 | 按产品入口控制 | 按产品入口控制 | 按产品入口控制 | 默认拒绝/受限 |

## 每工具权限
- `allow`：允许。
- `ask`：执行前审批。
- `deny`：拒绝。

MCP 支持服务级 `server_permission` 与工具级 `tool_permissions` 覆盖。
