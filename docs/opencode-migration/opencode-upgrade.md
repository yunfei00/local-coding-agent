# OpenCode 独立升级

候选默认捆绑 [v2.2.6](version-lock.md)。设置的 About 页面可以主动检查升级。管理器核对上游下载来源、Windows x64 资产、版本、文件大小和 SHA256。候选在独立临时目录启动，测试认证、会话、事件、权限回复和环回模型通信。

检查通过后原子替换版本指针。回到内置版本时也校验 SHA256。执行中的任务阻止切换。资料缺失、文件被修改或兼容性检查失败时保留当前版本。

单元测试用受控下载数据。隔离验证也使用从 GitHub 下载并核对摘要的 v2.2.5、v2.2.6 官方归档执行解压、协议探测、切换与回退。应用原生 HTTPS 请求下载归档时在本机超时，隔离验证改用 GitHub CLI 下载的真实字节。见[验收结果](acceptance-results.md)。
