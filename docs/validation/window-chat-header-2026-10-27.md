# 窗口行与聊天工具栏（2026-10-27）

用户补充的实际截图明确区分两个区域，修正此前把会话操作放进窗口行的实现：

- 全窗口 44px 第一行：后退、前进、侧栏折叠、文件/编辑/视图/帮助；右侧保留 Electron 原生最小化、最大化/还原和关闭按钮，保留中间拖动空间。
- 聊天区 48px 顶部：文件夹标识、会话名/项目名，以及 Open、Git、Task、Context、More。此行仅在聊天区，不跨过项目侧栏，不挤占原生窗口按钮。
- 设置页保留窗口行，隐藏聊天工具栏。深浅色继续使用用户参考截图取色。
- 后退/前进复用现有项目选择与会话读取 IPC，最多保留当前窗口内 50 条位置记录；不创建空会话、不调用模型。草稿仍按项目/会话恢复，历史不声称跨重启保存。删除会话后去掉对应历史记录。
- 侧栏可折叠和恢复，折叠状态单独持久化；聊天输入保持可用。执行中保持原有导航保护。
