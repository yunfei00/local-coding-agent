# 项目菜单与移出项目验收

## 实际行为

项目行的 `⋯` 放在最右侧写入图标之前，复用现有 ActionMenu、项目注册、SQLite 设置、会话创建和剪贴板/文件夹 IPC。菜单为：

1. 新建会话：打开草稿，首次提交内容才保存，不增加空会话。
2. 在文件资源管理器中打开：由后台解析指定项目 ID，打开该目录，不切换当前聊天；其他平台显示相应文件管理器文字。
3. 复制项目路径：复制完整后台项目路径。
4. 展开会话/折叠会话：只改变该项目的侧栏展开状态，不切换工作区。
5. 移出项目：分隔线后显示，弹框确认，可取消。

“移出”不是 SQLite 的级联删除：不调用原有 `delete_project`。通过原设置表的项目可见性标记隐藏注册入口，和活动项目回退设置在同一事务中保存；没有增加第二套项目/任务系统，也没有更改数据库 schema。文件、Git Worktree、会话、Task Plans、Checkpoint、上下文配置和 API 账本均保留。移出后默认不再构建该项目 Repository Map，重新添加同一路径时恢复原 ID、会话及任务，并刷新仓库信息。

移出非当前项目不影响当前会话；移出当前项目回到其他可见项目，移出最后一个项目回到空首页，不生成 New thread。前进/后退历史去掉该项目的位置。重启后仍保持移出，再添加原目录可恢复。

正在执行、无法确认执行归属或进程清理失败的项目会保留并提示先停止/诊断；不会偷偷取消其他任务。暂停、待审查及已完成任务可随移出保留原状态和预算。全局 API 预算继续包含移出项目的账本，不能用隐藏项目绕过额度。

## 更新和使用

更新源码后完整重启 Electron/Agent；仅刷新页面不能更新预加载 IPC。无需清空模型配置。打开项目右侧 `⋯` → 移出项目 → 确认；恢复使用 Projects 文件夹菜单 → Add existing folder，选择原目录。正在运行的任务先 Stop/Cancel；失败提示会留在确认框，不会将失败误显示成成功。
