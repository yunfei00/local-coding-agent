# v0.3 最后人工验收

自动化证据见 [最终验收记录](v0.3-final-validation.md)。以下只核对实际使用与视觉，不要求重新执行已经完成的开发测试。

1. 从仓库的 `desktop/release` 启动 `Local-Coding-Agent-0.3.0-x64-Portable.exe`，或使用同目录 Setup 在测试环境安装。若已有日常安装，请先使用 Portable，保留原数据。
2. 确认主界面正常显示、左下角 Agent Connected，模型选择中可见 `qwen2.5-coder:1.5b`。
3. 打开一个测试工程，创建 Thread，发送简短问候；检查消息显示、复制、Enter / Shift+Enter，以及运行中 Stop。
4. 切换浅色/深色主题，缩放窗口至较小尺寸，确认按钮、文本、代码和输入框没有遮挡或明显对比度问题。
5. 分别打开 Context、Git、Plan、Diagnostics，确认可以关闭，输入框始终可用；Git 的文件列表/Diff、Plan 状态和 Diagnostics 信息可读。
6. 展开多个项目，切换项目与 Thread，右键重命名；收起一个项目后退出并重启，确认收起状态、会话、标题和主题保留。
7. 检查每轮执行摘要和 Copy sanitized trace；对于真实 1.5B 模型没有发出工具请求的任务，不能把文字描述当成文件实际修改成功。
8. 确认上述实际体验符合预期后，回复“人工验收通过，可以合并”。如有问题，提供操作步骤即可，先保留 PR 开放。

附件明确要求人工视觉、首次使用与真实模型体验确认后才合并 main。因此自动化全部通过后仍等待这一步；不创建正式 tag，不发布 GitHub Release。
