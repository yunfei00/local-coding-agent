# 智能模型路由

模型区可选“自动选择”或现有具体模型；手动模式的自动回退默认关闭。自动模式仅从当前配置中选择，不硬编码候选名单、不修改用户配置。

能力分 SUPPORTED / UNSUPPORTED / UNKNOWN。已有真实探针与成功响应优先于用户声明；证据绑定模型配置指纹，30 天后失效。未知能力不作为自动选择依据；需在原模型配置中执行能力检测。界面显示配置上下文窗口，不能据此声称已验证服务端最大窗口。

普通问答要求 chat；工程操作要求 tools；视觉/Windows 操作要求 vision + tools；结构化请求要求 structured。选择考虑能力、配置窗口减输出预留、真实成功率、延迟，记录中文理由。当前实际模型与用户原始选择分别保存。

额度耗尽按连接及实际 model_id 共同停用，别名不能绕过；模型不存在、能力不符、上下文超限、请求超时或服务端 5xx 可以有限回退。DNS、代理、鉴权配置错误停止，不通过轮换模型掩盖。429 按 Retry-After 有界处理；等待超过 10 秒则明确停止并提示，不提前重试。最多 3 次模型切换，仍受原请求和任务预算约束。

冻结快照确保 Settings 变更不重定向运行中任务。切换保留原目标、工具执行事实、审批、计划与累计预算；未执行的截断响应会丢弃，不重放已成功的操作。

qwen3.8-flash、qwen3.7-plus 及规范化变体在路由、Provider 和探针入口禁止请求。Ollama 保留；本轮不连接或安装 Ollama。

冻结的客户端快照采用有效能力证据：例如真实视觉探测已通过而旧 Profile 未声明视觉时，派生快照可启用该能力，不改写用户 Catalog。未知仍不视为支持，已有失败证据优先于旧声明；窗口/截图上传仍需原审批。
