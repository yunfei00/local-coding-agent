# 项目长期记忆

记忆位于现有本地 SQLite 的 project_memories，按工程隔离。记录标题、类别、内容、来源文件及 SHA256、信任级别、更新时间和修订号。事务提交支持崩溃恢复；迁移不改写旧线程。备份应使用 SQLite 备份接口或退出应用后备份整个数据目录，不能只复制运行中数据库而丢失 WAL。

候选知识不能覆盖用户规则或已验证记录。模型提出的推测默认 candidate；仅实际文件扫描得到的技术栈/命令声明、独立验证成功的变更事实可自动标为 verified。用户在管理界面保存为 user。来源变化后标记过期，不注入旧事实；当前代码优先。相同标题去重，完全相同内容不增加修订；并发编辑使用 expected_revision 冲突检查。

Context 中展开项目记忆，可查看、搜索、编辑、删除、查看来源及关闭自动记忆。运行中禁止编辑，以保护快照；只读查询仍可用。关闭自动记忆后，仅明确授权的本次保存请求可写入。原始聊天不会整体存为长期记忆。

ProjectFiles 过滤凭据名称、私钥、Token、认证字符串及安全存储中已知密钥；候选记忆亦使用同一过滤。自由文本的敏感信息识别不是完整 DLP，用户不应把凭据作为项目知识输入。存储失败明确报错，不清空数据库；派生索引可重建，物理数据库损坏须保留原件再恢复备份。

用户以“记住：……”明确给出的独立约定会按原文保存为 user，不再依赖模型概括，关闭自动记忆也不影响这次明确保存。只提取句首或句号后明确标记的有界内容，经过同样的凭据过滤；失败会提示，不静默丢弃。模型生成的其它知识仍为 candidate。
