# 使用说明

首次启动选择或创建工程，配置OpenAI兼容连接，获取模型并保存。保存时检查API连接，不自动发送付费文本/能力探针。Ollama兼容保留，不要求安装。

在同一聊天框输入需求即可问答、分析、开发、测试和修复；复杂任务自动使用原计划与四角色。Enter发送、Shift+Enter换行，工具/计划/Context/Git按需展开。

聊天工具栏选择当前任务或项目权限；设置→权限与安全可设全局默认及覆盖。完全访问首次确认一次普通操作连续执行；可以随时改为只读并停止任务。高级覆盖有优先级，不要把全局默认变化误认为自动撤销任务覆盖。

缺少Git不妨碍工程和聊天。用户工程的Python/Node/uv/npm依赖可单独配置；应用内置后端不替任意工程安装开发工具链。

更新需用户确认下载和安装，安装前暂停、备份，重启核对版本。可在设置中备份和检查上次更新；失败保留数据，恢复步骤见 data-migration.md。

v1.0仍处于开发验收阶段，正式下载入口和已知限制见最终 acceptance-report.md。
