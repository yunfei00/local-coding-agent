# 安全更新

仅Windows x64安装版支持应用内安装更新；开发版和Portable提供明确限制。GitHub Releases为更新源，用户先确认下载，再确认暂停/备份/安装。没有后台静默安装。

只接受本仓库HTTPS资源、严格正式版本和唯一x64 Setup文件名。限制重定向域名、下载字节和总时长；解析SHA256SUMS.txt并校验实际字节，安装前再次检查防止下载后改变。确认后版本发生变化要求重新确认。

安装前原后端暂停运行与排队任务，备份SQLite和加密凭据，阻止新任务。下载/校验/备份失败不启动安装器。启动成功只记录pending，重启后核对实际应用版本；失败保留数据和备份，不承诺未经验证的自动回滚。

当前有12项更新单元测试，覆盖无更新、有更新、下载/校验/安装失败、安装前重校验、待确认版本变化、重启版本核对及安装版识别等分支。传输和安装器在单元测试中使用 Mock，不代表线上更新闭环通过。

实际安装版已通过官方 GitHub Releases 的“没有更高版本”检查；另用真实 v0.9 → v1.0 安装包完成手动覆盖升级与数据核对。两者不能组合冒充应用内更新下载 → 安装 → 重启的真实成功用例。本轮尚无可用于该完整路径的已发布新版本，状态保留 NOT RUN，属于正式发布门槛。

Windows 安装器实际创建的文件是 `Uninstall LocalCodingAgent.exe`，更新检测兼容此名称与旧带空格名称。Portable 和开发版不能据目录中任意 exe 被误识别成安装版。
