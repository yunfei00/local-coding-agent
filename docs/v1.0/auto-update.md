# 软件更新：方案 A

正式更新源为本仓库 GitHub Releases，仅 Windows x64。设置 → 关于 → 软件更新显示当前版本、平台、更新源、最新版本和说明。忽略 Draft 和预发布，严格比较 SemVer；安装版选择 Setup，Portable 单独选择便携包。

状态由主进程实际服务产生：IDLE、CHECKING、UP_TO_DATE、AVAILABLE、DOWNLOADING、VERIFYING、READY_TO_INSTALL、ERROR、CANCELLED。流式下载显示字节和已知总量；未知总量不伪造百分比。支持取消、重新下载，禁止并发重复下载。检查磁盘空间，限制大小、超时和重定向来源，在自有缓存目录使用临时文件与安全移动。

从同一 Release 获取 SHA256SUMS.txt，匹配唯一目标文件，流式计算 SHA256。缺失清单、哈希不符、缓存损坏或路径异常都不能打开。缓存恢复和用户点击打开时再次校验，防止下载后被修改。SHA256 不等于发行者身份认证；当前安装包没有可信代码签名。

校验成功显示：“安装包已下载并通过校验，请关闭软件后手动安装新版本。”用户可以打开安装包、打开所在文件夹或稍后安装。只有主动点击才调用系统打开。**不会自动暂停任务、退出 Agent、启动安装器、安装或重启；不提供自动回滚。** 请先保存工作、停止任务并正常退出，再手动安装。Portable 提示手动替换；备份为设置中的独立操作，见数据迁移文档。

更新管理器有29项测试，使用本地受控HTTP服务和实际字节/文件/哈希，生产下载传输只替换网络映射；另有6项版本/元数据检查。覆盖要求的20类路径及缓存、符号链接、元数据中途断开。测试不会执行下载的模拟安装器。

`scripts/validation/v10-plan-a-desktop.cjs` 在实际安装版检查进度、取消、错误哈希阻断、正确哈希、用户打开和重启缓存恢复，4项通过。Electron UI、IPC、后端、下载和文件真实；Release元数据/网络映射及系统打开回调受控，未提前发布v1.0.1。线上官方无更新检查通过；线上未来版本实际安装属于未执行覆盖，不再要求方案B的自动安装重启验收。
