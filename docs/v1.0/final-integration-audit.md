# v1.0 最终整合审计

2026-11-06；沿用 feature/v1.0-windows-release 和 PR #33。审计起点 e98c5d4，fetch后main仍7325c04；原附件和egg-info未跟踪目录保留。

## 最新用户决策

- 仅Windows x64 Setup、Portable、SHA256、中文发布说明；Ubuntu保留后端CI。
- 更新采用方案A：检查→流式下载→校验→用户主动打开并手动安装。禁止更新器自动暂停Agent、退出、安装、重启；不承诺回滚。
- 当前Windows实装验收即可，干净Windows和高成本四角色+GUI同任务组合不再是发布门槛。
- 既有真实模型、权限、GUI、恢复证据继续有效；历史组合失败不能改写为PASS。
