# 安全边界

不绕过UAC、锁屏、Windows安全/隐私机制，不关闭杀毒，不自动取得管理员权限。FULL_ACCESS的普通操作无需重复审批，但角色限制、冻结验收文件及高风险保护继续执行。

API Key仍由Electron safeStorage保护。备份只复制加密原件，安装包不含本机数据。加密凭据损坏保留原件，读取错误不回显内容；MCP凭据读取失败后禁止覆盖旧库。桌面运行日志按已知凭据和格式脱敏。不得宣称能识别所有未知密钥格式或提供OS沙箱。

delete_file只操作单个明确普通文件，先移入应用file-recovery；不递归删目录，不删除凭据、Git内部或系统文件。恢复信息保留本机。目录/批量/覆盖历史等高风险不能由完全访问跳过。

更新使用本仓库TLS与SHA256校验，不等价于独立代码签名。若没有签名证书如实说明，不绕过Windows拦截。发布必须等待安装及升级验收与CI门槛。

等待超时诊断仅复用desktop_inspect已有的脱敏控件信息，不回显expected原文、密码/编辑文档内容或UIA原始异常。新增测试覆盖这些路径；诊断增强不改变成功条件，不忽略失败、不放宽权限。
