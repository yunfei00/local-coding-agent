# 稳定性与低内存

复用 v0.9 上下文压缩、失败签名、有限修复、预算、Checkpoint、后台队列及GUI互斥。默认串行，不通过增大循环次数隐藏问题。

原进程层限制每次日志16MiB、内存输出200000字符，任务结束释放自有进程树。桌面运行日志新增长度限制、脱敏及轮转：每条约60KB，单文件2MiB，保留3份归档。历史任务/诊断JSON不因运行日志轮转而删除。

启动器和离线恢复共享DataLock，禁止同时使用同一数据目录。更新前暂停任务、等待自有进程退出、保存状态并备份；未知副作用不自动重放。资源不足记录BLOCKED_RESOURCE，不修改系统虚拟内存或终止用户程序。

长任务、内存趋势及安装版异常恢复的实际验收结果不能由上述机制推断，见验收报告。

## 本轮诊断与修复

- 冻结进程缺少动态时区模块导致窗口发现返回空列表。现在将请求 PID 的身份读取异常报告为具体环境错误，附带安全的异常类型；不再让模型反复尝试同一不存在的定位结果。
- Windows 前台激活失败时，只允许点击同一已校验窗口暴露的标题栏，操作前再次验证 HWND 和命中区域。不会点击客户区或遮挡窗口，不使用模拟 Alt、线程输入附加或系统策略修改。
- PowerShell 恢复原本不存在的环境变量时必须删除该变量。把 ELECTRON_RUN_AS_NODE 恢复成空字符串仍会触发 Electron 的 Node 模式，导致启动后很快以退出码0结束。本轮修复测试驱动并保留复现记录，不把它误归因于模型。
- 低内存下测试串行；本轮在线测试开始时可用内存约3.7GB，非分页池约2.5GB。没有清理用户程序或修改虚拟内存。锁屏时停止 GUI 输入，待实际解锁后补测，不绕过安全桌面。

本轮只验证有界任务与回归，不宣称通过24小时压力测试或长期内存无增长证明。

最后恢复补测修复：否定的“不是开发任务”不会作为开发意图；恢复会根据原始目标收窄旧GUI快照；GUI保存的数据文件不会触发无关工程代码测试，显式源码修改/终端修复在工具执行前拒绝。保留真实界面动作证据要求，不会让文字声称成功直接完成任务。最新安装版DeepSeek闭环验证源码不变、测试未执行、正常退出与授权撤销。
