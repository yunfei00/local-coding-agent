# v0.2 Phase 19 — Update Check + UI Polish 人工验收

> 分支：`feature/v0.2`
>
> 自动化已经覆盖：版本比较、stable release 过滤、离线失败、以及 `automatic=false / can_auto_download=false / can_auto_install=false`。本页只验证真实桌面交互。

## 1. 启动

Windows PowerShell：

```powershell
git checkout feature/v0.2
git pull
.\scripts\dev\start.ps1
```

## 2. 验证新版界面

重点看：

1. 左侧品牌、Project、Thread 层级是否清晰。
2. 顶部显示当前 Project / Thread，不再出现旧的 Phase 9 / Windows Packaging 占位文案。
3. Provider 状态显示 Provider + Model，在线/离线状态清楚。
4. 空 Thread 页面显示 Provider / Model / Permission / Context 概览。
5. Terminal、Diff Review、普通 Tool 卡片布局没有错位。
6. 输入框 Enter 仍然发送，Shift+Enter 仍然换行。
7. Turn 运行中不能切换 Project / Thread；Stop 后恢复。
8. 向上滚动后仍能看到“向下箭头”，回到底部后自动恢复跟随。

## 3. 验证手动更新检查

打开：

`Settings -> General -> Updates`

应看到明确说明：

- Update checks are manual in v0.2
- 不会自动下载
- 不会自动安装

点击：

`Check for updates`

正常联网时应显示：

- 当前版本
- 最新 Release 版本
- Up to date 或 Update available

如果存在新版本，只允许点击：

`Open release page`

它只能打开 GitHub Release 页面，应用内没有 Download / Install / Restart to update 等自动更新按钮。

如果当前网络无法访问 GitHub，显示 `Update check unavailable` 即可，应用不能崩溃，也不能影响聊天。

## 4. 验收结论

以上正常即可认为 Phase 19 人工验收通过。

Phase 19 不要求安装任何新版本，也不会修改当前安装程序。
