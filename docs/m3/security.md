# M3 权限与安全策略

桌面工具不继承 Full Access 的免审批待遇。默认没有桌面授权；Read Only 完全禁用。只有经过原 ApprovalManager 的明确审批，Server 才向 Registry 传递内部授权标志，直接调用 Registry 默认被拒绝。

审批范围按当前轮次和不可猜测 window_id 划分：枚举标题、控件树发送模型、本地截图、图像发送模型、窗口控制分别审批。用户可选择 allow_once、allow_turn 或 deny；高风险确认、坐标回退与按键调用使用唯一 call_id 的新审批，不能被以前的 allow_turn 静默覆盖。Allow turn 仅对同一轮次/窗口/类别生效，不授权其他窗口。恢复任务需重新枚举授权。

控件名称包含删除、发送、提交、支付、发布、安装等风险词或无可解释标签时，点击先报风险错误且不执行；模型需明确提出 confirm_risk=true，触发新审批。坐标点击、滚轮回退和非基础导航快捷键同样需要新审批。风险判断并非应用语义沙箱，不可把一次窗口授权理解为无限制系统授权。

每次 worker 验证当前交互用户、Session、Default input desktop、目标 PID 创建时间、窗口 generation 和完整性级别。不能跨用户/会话，不自动提权，不绕过 UIPI/UAC/锁屏。选择器限制在授权顶层窗口的 UIA 树内；坐标点必须命中该窗口，输入要求实际焦点正确。剪贴板不读取，键盘脚本不执行，系统切换/安全注意键不发送。

密码/Token/密钥类控件不可读取或输入，所有编辑值不出现在 inspect；type_text 的事件/审批参数统一省略 text，结果只返回字符数和匹配布尔值。疑似密钥格式文本拒绝。截图在保存和生成模型附件前遮盖全部 Edit 与识别出的敏感控件，遮盖树不完整或捕获坐标未知时失败，不保存不确定的截图。像素级验收检查输入框真实区域全黑。

截图默认仅在本机保存，不自动发送模型。share_with_model=true 时审批明确提示图像可能发往在线第三方模型；窗口标题/控件树审批也明确提示回传模型。supports_vision 是显式能力声明，不根据模型名字猜测；模型不支持时只回传文本控件信息，不能宣称已视觉识别。任务结束清除内存图像附件。

全屏模式保留虚拟屏幕坐标与尺寸，但仅显示本次授权窗口，其余像素遮盖；不默认采集其他程序。截图仍可能包含控件外的自绘敏感文字，不能承诺通用秘密检测，授权前应检查应用内容。CI 只上传受控测试程序的脱敏 JSON 结果，不上传 PNG/JPEG、真实用户输入值、真实用户控件树或 API Key。

Stop/Task.cancel 会取消原协程，终止 Job 所属 worker，释放窗口范围并停止后续动作；M2 清理任务启动的应用进程树。SendInput down/up 一批提交，没有跨调用持续按键。已经提交到应用的操作或应用自己的异步工作不能撤销；Windows 不提供“撤销已发送点击”的机制。

不控制用户已有的无关应用进程；测试只清理实际记录的 fixture/worker PID，不按 node.exe/python.exe 等进程名全机清扫。
