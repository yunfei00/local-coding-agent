# v0.6.0 开发说明

主题：Unified Agent Runtime & Reliability。

- 同一聊天运行中可持久追加需求，在完整工具批次后的请求边界生效。
- 取消和完成的终态保护、启动并发保护与无 Plan 运行恢复。
- 请求准备、发送尝试、响应、失败与预算预检的关联事件。
- 诊断按需查看近期事件，完整历史留本机文件。
- 继续保留原计划、自动验证、预算、权限、MCP、Git Worktree 与 Windows 工具能力。

升级需要完整退出并重启源码应用，确保 Electron 与 Python 后端同时更新。旧线程和配置保留；旧版未保存原目标的无 Plan 失败运行不能自动猜测恢复。

Python、React、Electron 已通过真实在线开发验证；运行中追加、原任务恢复、网络断流和实际 Windows UIA 操作均已取得证据。纯桌面动作与独立验收明确区分，不将点击成功等同于代码验证通过。

本文件是版本变更说明，不代表正式发布。最终 CI 与补充验收门禁以验收报告为准。本轮不创建正式 Release/Tag 或安装包。
