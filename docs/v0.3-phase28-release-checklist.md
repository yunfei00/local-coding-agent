## 本地自动验收

```powershell
uv sync --locked
npm.cmd --prefix desktop ci
uv run python scripts/validation/check.py
node scripts/validation/desktop-smoke.cjs

```

- Python unittest、TypeScript、桌面单元测试和 Build 必须全部通过。

- 测试涵盖面板打开时发送、复制、Stop、改名、失败草稿保留、重启恢复、主题和缩放；产出本地截图与 JSON。

- 迁移测试从正式 v0.2.0 的 schema 创建合成数据，只迁移其 SQLite 备份副本，核对项目、Thread、消息、设置和 Prompt Rules，再重启验证。
- 权限、MCP、Git 与 Worktree 的实际工具回归包含在 Python 套件内。

## Windows 打包

```powershell
.\scripts\build\package-windows.ps1
```

生成：

- `desktop/release/Local-Coding-Agent-0.3.0-x64-Setup.exe`
- `desktop/release/Local-Coding-Agent-0.3.0-x64-Portable.exe`
- `desktop/release/SHA256SUMS.txt`

脚本检查每个原生命令的退出码，限定清理路径，先验证打包 Agent，再执行完整打包桌面冒烟及 Portable/Setup 的启动连接检查。Setup 采用唯一安装目录；发现已有安装时保护原安装并停止该项，交由干净 Windows CI 验证。

## 合并条件

1. 最新实现提交的 Windows 和 Ubuntu CI 通过。
2. Setup / Portable 自动化冒烟通过，SHA256SUMS 已生成并复算一致。
3. 迁移、安全和功能回归通过；没有已知 P0/P1 程序问题。
4. 用户检查安装包首次使用、真实模型交互与 UI 视觉，并给出确认。
5. 重新 fetch main 检查并发更新，再按授权合并并验证 main CI。

用户已授权本任务的代码提交及在门禁全部通过后的主线合并；仍需等待附件要求的人工验收确认。保持现有 PR 开放。不自动创建 tag 或 GitHub Release，也不修改 `.github/release-trigger`。
