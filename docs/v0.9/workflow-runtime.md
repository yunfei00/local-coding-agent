# 工作流执行

执行复用原小写 Runtime 状态和 TaskPlanStore 子步骤状态，不强制改写旧数据库枚举。队列使用 queued/running/waiting_approval/paused/blocked/failed/completed/cancelled 元数据；实际成功与否以原 Runtime outcome、步骤及验证证据为准。

依赖图按拓扑就绪关系执行。后台多任务默认串行，可在工作流高级设置选择最多 2 个任务；只有工作区隔离、资源声明不冲突且至少 2.5 GiB 物理内存及提交余量时才允许并行。共享工作树、未知工作区、文件或工具资源冲突均保守串行；同一 GUI 焦点互斥。

同一会话运行中使用原追加需求入口，不能排队创建第二个执行循环绕过已有计划。其他会话可排队。旧前台任务仍使用原兼容断线行为，不与新后台任务并行。

步骤完成必须关联持久化成功工具记录。中断且结果未知的副作用继续使用原恢复审批，不自动重放。完成步骤不回退，验证命令可以按原 repeatable_check 规则安全重跑。
