# 后台执行与恢复

桌面统一聊天默认创建服务器拥有的后台任务。WebSocket 是事件通道；断线不取消该任务。重连重新读取原 Runtime 快照、事件与待审批请求，不重新发起任务。

用户可在执行卡点击“暂停任务”，在输入框停止按钮取消任务，或在暂停后检查并继续。暂停复用原预算与 Checkpoint。取消是终态，迟到事件不能恢复运行；显式恢复会开启新的尝试 generation，保留原运行证据。

后台队列本地持久化。应用退出取消自己拥有的执行并释放子进程；重启把未完成队列标记 paused，原 Runtime 恢复机制保存未知副作用，不盲目自动执行。

排队时已经建立原 ExecutionBudget 的零调用运行记录，冻结设置、角色模型及用户目标。未开始的排队项重启后也能通过原运行恢复入口继续，API/工具次数保持零；不自动启动。取消排队任务会持久化取消终态。没有创建副作用证据或伪造完成。
