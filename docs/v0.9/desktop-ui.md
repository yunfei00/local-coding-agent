# 桌面交互

保留单一聊天输入框，不增加“多 Agent 开发模式”。复杂任务自动使用原计划区域展示依赖、角色、验收要求、真实完成数/总数及角色交接中的实际模型。

执行卡可展开验证命令与退出码、调用及恢复信息、交付报告路径，保留原诊断导出。运行中提供暂停，暂停后提供检查恢复，停止按钮继续可取消。排队根据后台任务真实状态展示，不按模型自然语言估算百分比。

模型设置中增加一个可展开的自主工作流区：四角色模型、有限修复/无进展参数、并行上限及内置模板说明。修改设置面向新任务，运行快照保留。

Git、Context、Pinned Files、MCP、模型配置与聊天滚动保持原结构。低内存采用串行与资源门禁，不额外启动管理后台。
