# v0.2 Phase 15 — Terminal / Tool Stream 人工验收

> 分支：`feature/v0.2`
>
> 本文只验证必须由真人观察的桌面实时体验。Python/TypeScript 自动化测试和 Windows/Ubuntu CI 已覆盖协议、事件顺序、限流、超时和取消逻辑。

## 1. 启动当前开发分支

在 Windows PowerShell 中进入仓库：

```powershell
git checkout feature/v0.2
git pull
.\scripts\dev\start.ps1
```

如果本机依赖尚未初始化，`start.ps1` 会自动调用 bootstrap。

打开任意测试项目，Permission 保持 `Workspace`。

## 2. 验证实时 stdout / stderr

发送下面的消息给 Agent：

```text
请只执行下面这条命令，不修改任何文件：
python -u -c "import sys,time; print('out-1',flush=True); time.sleep(1); print('err-1',file=sys.stderr,flush=True); time.sleep(1); print('out-2',flush=True); time.sleep(1); print('err-2',file=sys.stderr,flush=True)"
```

应看到：

1. Terminal 卡片先显示 `Running`。
2. 能看到 PID。
3. 输出逐步出现，而不是命令结束后一次性出现。
4. stdout / stderr 都能显示，stderr 使用不同样式。
5. 最终显示 `Completed`，并显示耗时。
6. 输出过程中桌面仍能正常滚动和响应。

## 3. 验证 Stop 与进程树终止

发送：

```text
请只执行下面这条命令，不修改任何文件：
python -u -c "import time; print('started',flush=True); time.sleep(120)"
```

看到 `started` 后点击右下角 `Stop`。

应看到：

1. Terminal 状态从 `Running` 进入 `Stopping…`。
2. 随后显示 `Stopped`。
3. 卡片显示进程树终止原因 `user_cancelled`。
4. 不需要等待 120 秒，进程应很快结束。
5. Send 按钮恢复可用，可以继续下一条消息。

## 4. 验证大输出保护

发送：

```text
请只执行下面这条命令，不修改任何文件：
python -c "print('X' * 150000)"
```

应看到：

1. 应用不会明显卡死。
2. Terminal 输出仍可滚动。
3. 卡片出现 `Output limited` 或“Live output was limited…”提示。
4. 命令仍能正常结束，最终状态为 `Completed`。
5. 后续聊天和发送消息仍正常。

## 验收结论

以上三项全部正常即可认为 Phase 15 人工验收通过。
