## 决策 C

换模型当前收益有限。Gemma 可完成 CLI 和待办定向复验，库存仍未稳定。最小下一步是在现有工作流内将生成验证脚本显式分配给 Developer，Tester 仅运行冻结的验证命令。测试缺失时记录结构化阻断并交给原修复流程，保持 Tester 权限。状态型验证在同一隔离数据集里用一个可审阅脚本验证写入前后状态，任意命令仍受重复防护。先用确定性回归覆盖交接，再少量复验 30。

| 方案 | 证据与代价 |
|---|---|
| 本地优先 | 2/5 真实尝试通过，04 和 P1 证明有改善空间，无在线费用及项目外发 |
| 混合路由 | 已有路由可复用，Kimi 接入受阻，目前没有可比成功率、耗时或实际费用。真实代码外发仍需授权 |
| 手动选模 | 保持现有选择，暂缓自动回退或默认在线依赖 |
