- 同一聊天页面启动自主开发、查看计划/工具/测试/Diff/交付报告、暂停/停止、追加需求；追加复用 Task、Worktree、已完成步骤、模型和累计预算，重启后恢复真实消息与进度。
- 连接与 Model Profile 跨 Provider 路由、单在线 Executor、独立视觉 Observer，保留高级四角色/Local-first 配置及旧任务快照。
- Planning 有界重试、实际 Usage 与保守预算结算、任务诊断导出、上下文裁剪、Checkpoint、无进展/重复操作保护、WebSocket 重连同步。
- 失败工具的错误完成反馈和视觉格式修复均有明确上限，仍经过原预算、权限和审批。GUI 失败断言进入修复上下文，截图保留隐私遮盖并向模型说明脱敏区域。

## 使用与边界

输入框选择“自主开发 · 自动验证”，选择已配置的在线模型后发送目标。结束或暂停后在原输入框追加；运行中消息排队/实时引导尚未支持。既有任务保留模型与预算快照，底部换模型不会暗改旧任务；需要时使用高级配置或新会话。

已保存的模型凭据、会话、Task、Checkpoints 和用量记录保留。升级前退出旧应用，安装后完整重新启动；Portable 亦需重新启动进程。执行项目测试仍需要项目对应的 Git、uv/Python、Node 等开发工具，安装包内置 Agent 不替代各工程的开发依赖。

本机 Ollama 服务可连接，但 qwen2.5-coder:1.5b 连续四次无效计划后停止，API 调用为零；该模型完整自主任务未通过。部分 API 配置仍返回 403/400，Qwen3.7-plus 在 GUI 场景存在不收敛案例。不能保证所有模型与所有项目同等可用；真实 CPU Local-first→强 API 回交组合不在本次在线发布的实测准入范围内。
