# 测试用例

A 创建、读取、重命名、修改、删除、跨文件引用及不存在文件后的恢复。检查最终内容、文件存在性及失败读取工具证据。
B Python CLI 的创建、列表、更新、删除，JSON 持久化及非法输入；从外部启动多个进程交叉检查退出码与数据。
C 植入一个错误函数及不变的断言。检查真实失败与成功退出码、测试文件不变及独立 pytest。
D 从需求实现 slugify 与 pytest 用例。检查模型发起的成功命令、独立 pytest 和外部边界用例。
E 初始化 Git、创建分支、提交、检查未提交差异和恢复文件。检查实际分支、提交内容、工作树及工具事件。
F-vision 以隔离窗口截图验证像素识别。F-desktop 验证 UIA、窗口切换、点击输入及记事本。两项单独计分，若没有隔离目标和真实模型工具证据，记录阻断。

每模型每项计划三轮，单轮 240 秒，18 模型步骤，8192 Ollama 上下文设置。两模型共用同样的输入与规则。仅批准列明的变更和命令，继承项目权限保护。外部评分代码不在模型工作区。
