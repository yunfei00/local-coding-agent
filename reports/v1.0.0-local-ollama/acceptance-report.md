# v1.0.0 双 Ollama 自动验收

原版以已安装的 v1.0.0 冻结后端为验收入口。源码修复使用独立后端进程复测，安装版和原用户会话保留。结果按 PASS、FAIL、BLOCKED 区分，原版与源码复测分开计分。

原版 42 个计划轮次全部取得可判定结果，覆盖率 100%。5 轮通过、37 轮失败、0 轮仍阻断。Gemma 为 5/21，文件 3/3、视觉 2/3。Qwen 为 0/21。

Gemma 的记事本三轮已发现指定窗口并尝试真实 UIA，三轮均记录 DESKTOP_FOCUS_FAILED，随后由工具循环保护停止。原生 worker 的独立 WinForms 对照通过。这两个结果分属不同测试路径。Qwen 首轮视觉请求超时，随后会话锁定。桌面恢复后只补跑原先锁屏阻断的五轮，使用对应的原测试输入和超时，均实际执行并超时。旧阻断记录保留在 gui_replaced_attempts。

覆盖结果与原始错误码见 results.json，逐类分数见 model-comparison.md。Windows 原生工具独立对照通过，计分仍要求指定模型经 Agent 执行，并有独立可验证证据。

两个确认缺陷分别为英文诊断并修复被误判为只读、无 Git 工程仍被要求提供 Git diff。源码修正后，Agent Loop 12 项、Unified Runtime 45 项回归通过。Gemma 的 C/D 源码真实复测各 3/3，Qwen 两项合计 0/6，均超时。修复提交为 d1b9eaf、7524aa4。

当前部署未达到稳定自主开发的验收门槛。剩余风险包括 Gemma 的输出截断、计划证据不足和记事本前台激活失败，以及 Qwen 的请求超时和空响应。安装目录的首次探测残留及其清理阻断见 defects.md。
