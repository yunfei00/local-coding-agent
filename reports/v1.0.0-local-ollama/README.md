# v1.0.0 双 Ollama 实测

在当前安装版的冻结后端上，通过认证 WebSocket 的 project.open、turn.start 和审批协议执行。每轮独立启动后端，数据库和项目都在系统临时目录，原安装版进程继续运行。Ollama 的 /api/tags 只用于预检，生成请求由产品发起。

运行 `pwsh -File reports/v1.0.0-local-ollama/run-tests.ps1`。需要当前安装版正在运行并已有两种模型的 Ollama 配置。pytest 通过 uv 临时依赖提供。项目和原始证据保存在本机供复查。

外部断言决定分数，原 Agent 的结束状态单独保留。阻断不计成功。部分输出和本机路径不随报告提交。

耗时包括独立后端启动、Agent 执行、评分和收尾。Token 只累计服务实际回报且已完成的响应。未回报的用量为空，超时请求可能没有完整用量。自动修复与工具协议补正分别计数。
